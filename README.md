# 💖 Just For You Valentine

A beautiful, interactive Valentine’s Day web experience built with **React**, **Vite**, **TypeScript**, and **Tailwind CSS**.  
Designed to express love through animations, photos, messages, and cute stickers 💌

🔗 **Live Demo:** https://just-for-you-valentine.vercel.app  
🔗 **Repository:** https://github.com/maverickxjames/just-for-you-valentine

---

## ✨ Features

- 💝 Romantic, animated UI
- 🖼️ Photo cards with flip animation
- 🎉 Cute stickers (PNG + GIF support)
- 💫 Smooth animations using Framer Motion
- 📱 Fully responsive design
- ⚡ Fast build with Vite
- 🧠 Type-safe code using TypeScript

---

## 🛠 Tech Stack

- **React**
- **Vite**
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion**
- **shadcn/ui**
- **Radix UI**

## 📦 Installation

### Prerequisites
- Node.js (v16 or higher)
- npm / yarn / pnpm

### Clone the repository
```bash
git clone https://github.com/maverickxjames/just-for-you-valentine.git
```
### Install dependencies
```bash
cd just-for-you-valentine
npm install
```
### 🚀 Running the Project

```bash
npm run dev
```
### Project Structure
```bash
├── public/
├── src/
```
